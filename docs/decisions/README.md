# Architecture decision records

One file per architectural decision, numbered in the order taken. A record is never edited after it is accepted, except for its Status line. To change a decision, write a new record that supersedes the old one.

When a decision changes the architecture, update the matching diagram in the same change.

Format: Status, Date, Context, Decision, Alternatives considered, Consequences.
